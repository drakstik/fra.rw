# Project Overview
This project is for a website belonging to Fragile Ltd., a Rwanda-based skateboarding community and brand (similar to Stussy). 

The website will have items for sale (skateboard, clothes, shoes, etc...), as well as articles with videos & pictures.

There are 3 user roles:
- Customer
- Operator
- Admin

The Admin role has access to the entire DB.
The Operator role can post items for sale and publish articles. 
The Customer can shop and read the published articles.
